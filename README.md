# 阿含缘起觉察助手 · Ahāna Yuantqi Awakening

> ### 🌱 我希望这个能帮助到别人。
>
> 用它，把一团乱的情绪，拆成一条可以看见的因缘链——看见烦恼从哪里来，就知道它可以在哪里松开。

一个以**阿含经·四圣谛 + 十二因缘**为思维模型的**烦恼觉察分析工具**。它不是一个宗教修行引导，也不是心理咨询或医疗诊断，而是一副帮你观察自己情绪与念头的"因缘放大镜"。

当你感到焦虑、内耗、委屈、愤怒、嫉妒、悔恨、莫名空虚，或放不下某件事时，它会：
1. 识别你现在是哪种苦（苦苦 / 坏苦 / 行苦）
2. 顺着十二因缘，把你的烦恼拆成一条可见的链条
3. 帮你找到这条链上**最容易切断的一环**（断点）
4. 给你一个 1 分钟、当下就能做的觉察练习

---

## 它是什么

| 维度 | 说明 |
| --- | --- |
| 理论基底 | 杂阿含、长阿含原始缘起思想（四圣谛、十二因缘、八正道） |
| 核心框架 | 苦谛识别 → 集谛拆解链条 → 灭谛定位断点 → 道谛觉察练习 |
| 苦的分类 | 优先三苦（苦苦/坏苦/行苦），附带八苦补充 |
| 工作方式 | 顺观十二因缘（默认）/ 逆观回溯 / 案例练习 / 术语查询 |
| 边界 | 不做算命、祈福、神通、前世因果审判；不替代心理治疗与就医 |

## 文件结构

```
ahan-yuanqi-juecha/
├── SKILL.md        # 主文件：角色、理论约束、四步SOP、安全红线、可用指令
├── knowledge.md    # 知识库：术语词典、精选阿含经文、8个示范案例、练习模板、误区黑名单
└── README.md       # 本文件
```

## 怎么使用

1. 把 `SKILL.md` 作为 Skill 的主提示词（含 frontmatter，可直接被识别加载）；
2. 把 `knowledge.md` 作为知识库 / 参考文件；
3. 向它描述一段你的烦恼，它会按四步流程拆解；可用 `逆观`、`案例练习`、`术语查询 词汇`、`换断点`、`精简拆解` 等指令切换模式。
